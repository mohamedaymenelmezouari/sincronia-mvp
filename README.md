# SincronIA — MVP

> El agente de IA que gestiona tus turnos. / The AI agent that manages your shifts.

## Setup (ES)

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Setup (EN)

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploy

```bash
npx vercel --prod
```

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion
- Radix UI (Slider, Accordion)
- Lucide React

## Features

- Bilingual (ES/EN) — language toggle in navbar
- Animated WhatsApp chat mockup (hero)
- Live ROI calculator with animated counters
- Annual/monthly pricing toggle
- FAQ accordion
- Fully responsive (375px+)
- Dark mode ready via Tailwind `dark:` classes
